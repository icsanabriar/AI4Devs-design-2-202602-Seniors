# Commit message examples (project format)

Format: `type(scope): Imperative description`

```text
feat(dn): Add new diagram for candidates component
```

```text
docs(doc): Describe main ATS functions in LTI deliverable
```

```text
fix(prompts): Correct numbering order in prompts log
```

```text
chore(repo): Add contributor folder layout note to ReadMe
```

```text
feat(dn): Add C4 container diagram for screening service
```

```text
docs(rules): Align deliverable checklist with course brief
```

Multi-line (optional body):

```text
feat(dn): Add data model ER diagram

Replace provisional list with Mermaid ER including entities and types.
```
